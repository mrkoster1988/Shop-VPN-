# Pushok

Главная ссылка всей экосистемы по указанию пользователя от 22.11.2026 — **https://t.me/pushok_app** (`@pushok_app`). Регистрация, оплата, управление доступом и ссылки аккаунта должны быть связаны с этой точкой входа. Не создавать отдельного бота для Pushok Flow. Существующие секреты и явно настроенную идентичность бота нельзя молча заменять: изменение кода не является подтверждением настройки работающего сервиса.

Pushok Flow получает серверы через персональную HTTPS-ссылку `/sub/{token}`. Токен ссылки даёт доступ к конфигурации, но не заменяет авторизацию аккаунта. Не включать его в журналы, публичные документы или запрос страницы перехода. Состояние оплаты и срок доступа определяет сервер магазина; приложение отображает полученные сведения.

Проверки кода и публикация релиза не заменяют приёмку платежей, выдачи и реального трафика на работающей инфраструктуре. Сохранять штатный порядок публикации после полного CI.
