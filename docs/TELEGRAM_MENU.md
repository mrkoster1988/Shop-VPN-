# Редактор Telegram-меню — v0.053

## Где находится

Только для владельца: `https://ваш-домен/shop/admin` → «Редактор меню Telegram».
У пользователей с ролями поддержки, финансов, оператора панелей и менеджера MTProxy нет доступа к API чтения/записи меню.

## Возможности

| Код | Действие | По умолчанию |
|---|---|---|
| `buy` | Открывает Mini App магазина по `PUBLIC_URL` | «Купить / продлить VPN» |
| `account` | Создаёт одноразовую ссылку входа в браузер, действующую 5 минут | «Открыть кабинет в браузере» |
| `support` | Отправляет актуальный текст поддержки через проверенный callback | «Поддержка» |
| `terms` | Отправляет актуальные условия продажи | «Условия продажи» |
| `link1`, `link2` | Внешняя публичная HTTPS-ссылка | Выключены |

Редактируются текст кнопки, видимость (кроме обязательной покупки), номер строки 1–6 и URL дополнительных ссылок. Не больше двух видимых кнопок в одной строке. Сохранённые изменения применяются только к следующим ответам на `/start`, `/buy`, `/account`; старые сообщения Telegram не обновляются.

Ссылки принимаются только по HTTPS, без учётных данных в адресе, фрагмента и локальных доменных имён; максимум 512 символов. Не храните в публичных URL токены или конфиденциальные данные. `callback_data` системных действий нельзя изменить на произвольную команду.

## Проверка без Telegram

Предпросмотр справа/ниже формы показывает состав строк и подписи. Он не создаёт временную ссылку входа, не отправляет запросы к Telegram и не подтверждает доставку. После сохранения версии настройки прочитываются ботом из SQLite при новом сообщении.

API `GET /api/admin/bot-menu` и `PUT /api/admin/bot-menu` используют существующую HttpOnly-сессию сотрудника с ролью owner. Запись атомарна и защищена `version`: при конфликте возвращается HTTP 409, нужно обновить страницу. Действия регистрируются стандартным аудитом административных запросов. Восстановление копии базы включает меню автоматически.

## Приёмка на VPS

1. Обновить магазин до v0.053 через управляемое обновление после резервной копии, не запускать вторую копию бота.
2. Войти владельцем, выключить «Условия продажи» только в меню, переименовать «Поддержка», сохранить; проверить повторное сохранение и 409 при открытых параллельных вкладках.
3. Отправить боту `/start` и проверить реальные кнопки, раскрытие Mini App и одноразовую ссылку кабинета.
4. Проверить поддержку и условия отдельными командами независимо от их видимости в меню; покупка Stars и выдача VPN должны остаться без изменений.
5. Добавить публичную HTTPS-ссылку на собственный Telegram-канал, проверить открытие в клиенте. Убедиться, что в админке и логах не появляются билеты входа.

Критерий готовности — успешные автоматические проверки и отдельно подтверждённое поведение реального бота.
