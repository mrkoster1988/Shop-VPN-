# Бесплатные тарифы Shop — управление и ограничения (24.11.2026)

## Настройка
Администратор создаёт тариф с ценой **0 ₽ и 0 Stars**. Ненулевое значение хотя бы одной цены делает тариф платным; смешанная комбинация ноль/неноль отклоняется.

- **Срок:** от 1 до 3650 дней, определяется полем «Срок, дней».
- **Активаций всего:** 0 — без общего лимита; любое положительное значение ограничивает число бесплатных заявок по тарифу среди всех аккаунтов (атомарная проверка в момент выдачи).
- **На аккаунт:** один бесплатный заказ данного тарифа на данный протокол; действующая подписка того же протокола блокирует новую бесплатную выдачу.
- **Трафик на профиль 3x-ui:** 0 — без лимита; 1–10000 ГБ задаётся через `totalGB` клиенту 3x-ui (VLESS/VMess), проверяется чтением записи после изменения; для WireGuard, Hysteria2, TUIC оформление тарифа с такой квотой отклоняется.
- **Автоматическое продление:** выключено по умолчанию. При включении нужно выбрать 1–12 продлений. Дополнительные периоды берутся из первоначального тарифа; число продлений и условия фиксируются при оформлении. Планировщик помещает продление в очередь незадолго до истечения срока; после подтверждённой выдачи увеличивает счётчик. При переходе на платную подписку автопродление прекращается.
- **Квота + автопродление:** пока не допускается, потому что сброс накопленного счётчика 3x-ui при продлении не подтверждён.

## Границы поддержки
Ограничение скорости **не реализовано**: для него нужно отдельное подтверждённое средство применения и проверки на каждом серверном адаптере. Для WireGuard/WGDashboard лимиты трафика также **не включены**. Не заявлять эти параметры как действующие пользователям.

Обновление исходников само по себе **не развёртывает** сервис на VPS. Требуется бэкап базы, миграция, проверка серверных адаптеров и end-to-end сценарий выдачи/продления на тестовом аккаунте.

## Проверки перед публикацией
- Бесплатный тариф сохраняется/публикуется и оформляется без платёжного счёта.
- Лимит активаций работает при параллельных заявках, не списывается при отклонённом оформлении.
- Переход на платный тариф и запрет повторной бесплатной активации сохраняют существующий доступ.
- Квота устанавливается и подтверждается на VLESS/VMess, а несовместимые протоколы отклоняются.
- Автопродление делает не более заданного числа дополнительных выдач, повтор воркера не удваивает срок.
- Сбои панели не оставляют данные пользователя доступными сверх заданного срока, повторные попытки сохраняют идентификаторы.
