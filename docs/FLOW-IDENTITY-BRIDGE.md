# Pushok Flow: связка MTProxy → Shop

Первый этап доступен только если владелец установил одинаковый случайный секрет
`FLOW_SHOP_BRIDGE_SECRET` (64 строчных hex-символа) **на сервере MTProxy и Shop**.
Без секрета обмен отключён (HTTP 503). Ключ не передаётся Android, в ссылки и логи.

## Запрос / ответ

`POST /api/flow/bridge/exchange` JSON:
`{"ticket":"psb1.<payload>.<hmac>"}`.

Старое поле `client_id` допускается для совместимости с установленными Flow v0.61 и ранее, но больше не используется для проверки доступа, записи привязки или ограничения устройств.

Ответ без постоянных токенов авторизации Shop:
- `active` + `subscription_url`: личная HTTPS-подписка WG, схема Flow v1;
- `pending`, `expired`, `revoked`, `disabled`, `unavailable`,
  `link_disabled`: `subscription_url=null`.

`Cache-Control: private, no-store`. Ответ не содержит ни личных данных Shop,
ни конфигурации peer, ни ключа WGDashboard.

## Ограничения безопасности

- HMAC-SHA256 с доменом `pushok-flow-shop-v1\\0` и отдельным серверным ключом.
- Подписанный ticket живёт ровно 60 сек, поля проверяются строго.
- Случайный `jti` гасится транзакционно: повтор запрещён, даже после ошибки получения ссылки.
- Telegram ID берётся **только из подписанного билета**, не из запроса пользователя.
- MTProxy UUID и Telegram ID привязываются к Shop user_id с запретом конфликтов.
  Не допускается поиск/слияние по @username или email.
- Доступ привязан к подтверждённому **аккаунту Shop** по Telegram ID, а не телефону.
  Сохранившиеся старые хеши `flow_bridge_devices` игнорируются и не блокируют
  повторную авторизацию на другом телефоне. Подписка и срок одни для аккаунта.
  Одновременное использование одного WireGuard private key на нескольких
  устройствах может вызвать переключение endpoint — для устойчивой параллельной
  работы нужны независимые peer в рамках одного аккаунта.
- Подключение выдаётся **только при действующем праве доступа в Shop**.
  Для новых пользователей запись может резервироваться только если владелец
  уже включил ограниченную политику `flow_auto_policy`. Сам обмен не покупает
  платный тариф и не подтверждает оплату.
- Отключённую пользователем HTTPS-ссылку приложение не включает повторно.
- Выданный peer отключается по истечении срока на WGDashboard; отзыв ссылки
  не равен отзыву peer.
- Функция проверяется на тестовом аккаунте и узле WGDashboard до массового
  включения. Не считайте текущую публикацию исходников развёрнутым сервисом.
