# Референсы UX и архитектуры Shop VPN (10 ноября 2026)

## RemnaShop — только источник идей

**Решение владельца:** RemnaShop не устанавливаем, не поддерживаем как отдельный продукт, не добавляем в Docker Compose, не вводим его API/БД как зависимость Shop VPN и не копируем его название или оформление. Изучаем открытые реализации и выбираем лучшие **подходы**, которые переосмысляем и реализуем собственным кодом Pushok.

Проверенный первоисточник: [snoups/remnashop](https://github.com/snoups/remnashop), последний опубликованный в просмотренном репозитории релиз v0.8.2. Источники наблюдений:
- [настройки кнопок меню](https://github.com/snoups/remnashop/blob/main/src/application/use_cases/misc/commands/menu_editor.py);
- [шаблоны русских текстов интерфейса](https://github.com/snoups/remnashop/blob/main/assets/translations/ru/buttons.ftl);
- [фабрика платёжных шлюзов](https://github.com/snoups/remnashop/blob/main/src/application/use_cases/gateways/queries/providers.py);
- [контракт шины событий](https://github.com/snoups/remnashop/blob/main/src/application/common/event_bus.py);
- [лицензия MIT](https://github.com/snoups/remnashop/blob/main/LICENSE).

Это **анализ исходного кода**, а не проверка реального сервера, качества всех функций или совместимости с Shop VPN. Исходные файлы RemnaShop в репозиторий Shop VPN не переносились.

## Что полезно для нашего продукта

| Наблюдение в референсе | Уже есть в Shop VPN | Собственное улучшение |
| --- | --- | --- |
| Редактор текста/ссылок/медиа кнопок и отдельное подтверждение изменений | Базовое меню Telegram, команды поддержки/условий | Настраиваемое меню в админке: предустановленные безопасные действия, предпросмотр, проверка URL/длины и аудит, откат изменений |
| Отдельные шаблоны текстов и кнопок для русского языка | Русскоязычный UI и редактируемые условия/поддержка | Вынести текст интерфейса из Python и JS в собственный каталог локализации; затем при необходимости добавить другие языки |
| Фабрика платёжных шлюзов и проверки `active/configured` перед использованием | Telegram Stars, ЮKassa/ручная оплата и статусы в коде | Единый интерфейс платёжных адаптеров с явно настроенным способом и проверенным получением/подтверждением платежа; первоочередной отдельный сценарий СБП |
| Контракты событий и отделённые обработчики | Очереди выдачи, повторные попытки, журнал событий оплаты/выдачи | Постепенно разделить крупные обработчики API, оплату, выдачу и рассылку, не меняя схему базы без миграций |
| Кнопки устройств, продления и кабинета; тексты ошибок | Устройства/перевыпуск, кабинет, уведомления о выдаче и продлении | Упростить клиентский маршрут до «купить → оплатить → подключить», дать понятный статус оплаты/выдачи и инструкции по платформам |
| Разделённые сегменты рассылок/аудитория | Сервисные уведомления; нет подтверждённого массового маркетинга | Позднее: сегменты/согласия/отписка, лимиты и проверяемая доставка без выдачи исходных токенов |

## Что сознательно НЕ заимствуем

- Зависимость от конкретной панели или её модели аккаунтов: Shop VPN должен подключаться к 3x-ui, WGDashboard и другим совместимым панелям через отдельные адаптеры, без скрытого fallback.
- Прямое объединение пользователей Telegram/VK/MAX/Matrix по совпадающим идентификаторам.
- Цветовую схему, чужой маскот, название, тексты кнопок, баннеры и прочие фирменные элементы. Бренд Pushok — собственный рыжий кот, бирюзовый/тёмно-синий/оранжевый карандашный стиль.
- Развёртывание исходного Docker-стека RemnaShop либо подключение его базы.

Если в будущем будет использован **фрагмент кода**, а не только идея, отдельно оценить лицензию и сохранить необходимые уведомления MIT и авторство; копирование не требуется для текущего плана.

## Приоритет реализации

1. **Следующий функциональный этап:** редактируемое Telegram-меню с проверкой действий и ссылок, предпросмотром и аудитом. Первое собственное внедрение готово в коде v0.053; не проверено на живом Telegram/VPS.
2. **Платежи:** формализовать платёжные адаптеры, отдельно проверить поддержку СБП у выбранного оператора, webhooks, идемпотентность, возвраты; Telegram Stars сохранить. Реальная приёмка на VPS обязательна.
3. **Собственный UI и локализация:** фирменный интерфейс Pushok и каталог строк без копирования чужих ресурсов.
4. **После стабилизации MVP:** сегментированные уведомления/рассылки, а затем VK/MAX/Matrix при наличии актуальных официальных API и отдельной авторизации.

Статус всех этих следующих функций: **не реализованы в v0.052 только на основании этого обзора**.
