# Иллюстрации технологий Pushok

Пять отдельных изображений созданы 12 ноября 2026 для README Shop VPN встроенным генератором изображений. Это оригинальная визуальная серия Pushok, не официальные логотипы перечисленных технологий.

| Файл | Сюжет |
|---|---|
| [3x-ui.png](3x-ui.png) | Кот Pushok управляет доступами у серверной стойки |
| [wgdashboard.png](wgdashboard.png) | Панель с подключёнными устройствами |
| [remnawave.png](remnawave.png) | Центральная консоль пользователей и серверные узлы |
| [wireguard.png](wireguard.png) | Защищённый туннель между устройствами |
| [vless.png](vless.png) | Лёгкий маршрут соединения клиента и сервера |

Общий стиль: цветной карандаш, тёмно-синяя бумага, бирюзовые детали и оранжевые акценты; рыжий кот с бирюзово-зелёными глазами в бирюзовом худи со щитом. На изображении только название технологии. Без заявлений о партнёрстве или спонсорстве.

Точные запросы генерации сохранены в [prompts.json](prompts.json). Все карточки встроены в README локальными файлами и ведут на официальные ресурсы технологий.
