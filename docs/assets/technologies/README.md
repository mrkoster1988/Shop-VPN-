# Иллюстрации технологий puShok shop VPN

Серия из 14 отдельных иллюстраций: три панели и одиннадцать карточек протоколов (Shadowsocks и Shadowsocks 2022 объединены в одну карточку). Создана 12 ноября 2026 года встроенным генератором изображений. Это оригинальные изображения puShok, не официальные логотипы перечисленных технологий.

## Панели

- [3x-ui](3x-ui.webp) — Выдача, продление и отключение VLESS-клиентов через API.
- [WGDashboard](wgdashboard.webp) — Управление WireGuard peers и выдача конфигураций через API.
- [Remnawave](remnawave.webp) — Пользователи, сроки и подписки через прямой REST API.

## Протоколы

- [VLESS](vless.webp) — Лёгкий протокол с UUID. Защита и транспорт выбираются в конфигурации сервера: например, TLS или REALITY.
- [WireGuard](wireguard.webp) — VPN-туннель с ключами устройств. Конфигурация и QR-код для подключения.
- [VMess](vmess.webp) — Шифрованный прокси-протокол с UUID. Для новых конфигураций — аутентификация AEAD.
- [Trojan](trojan.webp) — Прокси-соединение с защитой TLS и аутентификацией по паролю.
- [Shadowsocks / Shadowsocks 2022](shadowsocks.webp) — Семейство шифрованных прокси. Метод шифрования и формат ключа должны поддерживаться клиентом.
- [AnyTLS](anytls.webp) — Прокси поверх TLS с настраиваемым дополнением пакетов. Требуется совместимое приложение.
- [Hysteria2](hysteria2.webp) — Прокси на базе QUIC, разработанный для соединений с потерями и нестабильным качеством сети.
- [TUIC](tuic.webp) — Прокси на базе QUIC с передачей TCP/UDP и несколькими потоками в одном соединении.
- [AmneziaWG](amneziawg.webp) — Основа WireGuard с дополнительной маскировкой признаков трафика.
- [OpenVPN](openvpn.webp) — VPN для пользовательских устройств, удалённого доступа и соединения сетей.
- [IKEv2 / IPsec](ikev2-ipsec.webp) — Защищённый доступ к сети: IKEv2 согласует параметры, IPsec защищает трафик.

## Стиль и использование

Цветной карандаш, тёмно-синяя бумага, бирюзовые детали и оранжевые акценты; рыжий кот с бирюзово-зелёными глазами в бирюзовом худи со щитом. Каждый файл содержит отдельную иллюстрацию. Первоначальная VLESS-иллюстрация использована как образец стиля для девяти новых сюжетов.

В README используются локальные WebP-файлы для быстрой загрузки, без внешнего хостинга изображений. Кодирование WebP меняет формат хранения, но не сюжет, подписи и композицию. Пять первоначальных PNG сохранены. Точные запросы находятся в [prompts.json](prompts.json).

Карточки ведут на официальные ресурсы. Изображения не доказывают работоспособность интеграций, партнёрство или спонсорство.
