# Мобильный Pushok Shop

Витрина использует компактные тарифы, закреплённую шапку и нижнюю навигацию. В Telegram Mini App нет второй панели навигации. Кабинет покупателя открывается на весь экран телефона: Доступ, Заказы, Бонусы, Помощь, Профиль. В профиле — Pushok ID, смена пароля и выход. WireGuard показывает отдельную кнопку Pushok Flow, ручную настройку и раскрываемое управление устройствами; ожидающий выдачи профиль не показывает ключи. Оформление заказа содержит краткий итог и раскрываемый промокод. Ссылки приглашения открывают бонусы, возврат из оплаты — заказы. Админка остаётся белой; нижние вкладки учитывают полномочия, меню поиска сворачивается, карточка пользователя и формы открываются полноэкранно.

Основные элементы нажатия не менее 44 px, поля мобильных форм 16 px, отступы safe-area, длинные значения переносятся. Масштабирование страницы не запрещено. CSS и JavaScript получают отпечатки содержимого при выдаче HTML.

CI запускает существующие сценарии и Chromium/WebKit mobile acceptance (320×568, 390×844, 430×932), включая имитацию Telegram Mini App. Проверки используют синтетические аккаунты, заказы и конфиги; скриншоты доступны как артефакты CI. Реальные телефоны, платежи, выдача peer и запуск установленного Flow проверяются отдельно на VPS. Схема базы, права, секреты, платежи и серверные привязки не меняются. Код становится доступным пользователю только после выпуска и обновления магазина.
