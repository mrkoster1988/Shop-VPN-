# Справочник протоколов puShok shop VPN

В кабинете владельца и оператора панелей появился раздел **«Протоколы подключения»**.
Карточки показывают назначение, серверные варианты, адаптеры магазина, требования
к клиенту и официальные ссылки. Фильтр оставляет все технологии, адаптеры в коде
или планируемые интеграции. Справочник не меняет настройки сервера и не включает продажи.

## Что означают статусы

- **Адаптер в коде:** магазин реализует выдачу, продление и отключение. Это не результат
  проверки конкретного VPS. Свободные серверы, их состояние и привязка подписки
  проверяются отдельно при заказе.
- **В плане:** технология включена в направление развития. У магазина пока нет
  реализованного пути выдачи; оформить заказ или trial для неё нельзя.

Наличие протокола в панели не означает готовность интеграции магазина. Серверный
API, формат выдаваемого профиля и реальный клиент требуют совместной проверки.
Протокол не определяет транспорт автоматически: TLS/REALITY, WebSocket, gRPC и
XHTTP учитываются в конкретной конфигурации, а не отдельными товарами.

## Совместимость на текущем этапе

Это карта для выбора следующего адаптера, не результаты испытаний всех сочетаний.
Указанные кандидаты не устанавливаются и не подключаются автоматически.

| Протокол | Реализованный путь магазина | Следующее условие совместимости |
|---|---|---|
| VLESS | 3x-ui Legacy / Clients JSON, Remnawave v3 | Версия панели, группы/входящий профиль, защита и транспорт выбранного клиента |
| WireGuard | Агент puShok / WGDashboard | Интерфейс, выдача .conf, реальный туннель и прекращение доступа по сроку |
| VMess | 3x-ui Clients JSON, AEAD, TCP/WS + TLS | Совпадение inbound, времени и TLS; импорт и реальный трафик в выбранном клиенте. [Настройка](VMESS.md) |
| Trojan | Пока нет; кандидаты 3x-ui / S-UI | Пароль, TLS, серверное имя, проверяемый отзыв |
| Shadowsocks / 2022 | Пока нет; кандидаты 3x-ui / S-UI | Конкретный метод, длина ключей и поддержка клиентом; 2022 проверяется отдельно |
| Hysteria2 | S-UI apiv2, UDP/QUIC + TLS, опционально Salamander | Импорт, реальный трафик и закрытие открытой QUIC-сессии после отзыва. [Настройка](HYSTERIA2.md) |
| TUIC v5 | S-UI apiv2, UUID + пароль, QUIC/TLS, ALPN h3 | Импорт, выбранные алгоритм/режим UDP, трафик и отзыв сессий. [Настройка](TUIC.md) |
| AnyTLS | Пока нет; реализация sing-box | Выбрать управляющий API, зафиксировать версии сервера и клиента |
| AmneziaWG | Пока нет | Отдельный адаптер и совместимые параметры версии; путь WireGuard не считается заменой |
| OpenVPN | Пока нет | Выбрать управляющий API, выдачу профилей и отзыв сертификатов/учётных данных |
| IKEv2/IPsec | Пока нет; серверный кандидат strongSwan | Метод аутентификации, доверие сертификатам, выдача и отзыв |

Для WireGuard доступны официальные клиенты Android, iOS, Windows, macOS и Linux.
Для остальных технологий список проверенных магазином приложений по ОС пока не
утверждён. Поддержка протокола ядром не гарантирует импорт каждой ссылки конкретным
приложением; при приёмке фиксируются версия приложения, ОС и формат профиля.

## API и сохранение совместимости

`GET /api/admin/protocols` доступен владельцу и оператору панелей. Он возвращает
`schema_version: 1`, `external_checks_performed: false` и список `protocols`.
У каждой записи есть `id`, `name`, `description`, `server_options`,
`client_requirements`, `documentation_url`, `implementation`, `adapters`, `driver_id`.
Профили серверов, токены, ключи и пользовательские данные в ответ не включаются.

`app/protocols.py` — единый справочник; из него также строятся варианты протоколов
в `/api/catalog`. Условия доступности по свободному серверу и текущему пользователю
применяются после получения этого списка.

| Идентификатор в справочнике | Идентификатор заказа/подписки |
|---|---|
| `vless` | `xui` |
| `wireguard` | `wg` |
| `vmess` | `vmess` |
| `hysteria2` | `hysteria2` |
| `tuic` | `tuic` |
| Остальные | `null`, не продаются |

Существующие ID заказов и подписок не переименованы. Сам справочник не требует
миграции БД; для паролей S-UI добавлены таблицы `hysteria2_credentials` и `tuic_credentials`. Название VLESS в магазине больше не привязано только к 3x-ui:
его может выдавать и уже реализованный адаптер Remnawave.

Добавление карточки не заменяет реализацию адаптера. Для нового `driver_id` нужны
явная маршрутизация провайдера, модели запросов, хранение, формы, выдача профиля,
продление, отзыв, повторы и проверки. Запланированные ID отклоняются до сетевых вызовов.

## Проверки и следующий шаг

Автотесты проверяют права, отсутствие доступа к приватным профилям при чтении,
невозможность заказа/trial/создания сервера для планируемых протоколов, отказ
провайдера до сетевых вызовов, старые ID продаж, экранирование карточек и ссылок,
фильтры, ошибки загрузки и поздние ответы после выхода.

**VMess AEAD через 3x-ui** реализован в коде: структурированный профиль TCP/WS + TLS,
создание/продление/отключение, дополнительные устройства и перевыпуск ключа. Проверены
повтор после потери ответа и отказ выдавать профиль при неподтверждённой записи.
Следующий шаг — стенд с реальным приложением и прекращением трафика после отзыва.
Hysteria2 теперь реализован через S-UI: случайный пароль, повторяемая выдача,
продление, отключение и закрытие сессий. Реальная приёмка остаётся отдельным шагом.
TUIC v5 реализован через отдельный профиль S-UI с проверкой UUID/пароля и ALPN.
Пять протоколов реализованы в коде, шесть остаются в плане. Следующий этап —
установочный релиз v0.055 и приёмка целевой инфраструктуры.
