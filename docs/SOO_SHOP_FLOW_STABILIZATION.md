# SOO Pushok — стабилизация Shop → Flow
База: main, commit 90401442ce9d8a9da40ac083988dc1b5fbc710c3.

## Интеграция
Сохраняем текущие маршруты Shop:
- GET /api/flow/wireguard/connections — поиск собственного доступа;
- GET /api/flow/wireguard/subscriptions/{sid} — документ v1 с сессией Shop;
- GET/PUT /api/flow/wireguard/subscriptions/{sid}/link — управление ссылкой;
- GET /flow/wireguard/{token} — документ v1 по персональной ссылке.

Эта ветка не добавляет дублирующие маршруты, не заменяет таблицы и не
меняет schema/version/revision/profile id. Старый PR #43 построен на
260e2b5 и содержит альтернативный код для дополнительных устройств.
Его нельзя сливать механически. PR #42 — проект контракта: перед внедрением
переносимых учётных данных нужно сверить его с рабочими API Shop и Flow.

## Исправления
- Проверка публичного токена, чтение текущего состояния профиля и запись
  revision теперь находятся в одной SQLite BEGIN IMMEDIATE транзакции.
  Это исключает публикацию устаревшего снимка после более новой записи.
- Публичный WG feed использует существующий бюджет 60 запросов в минуту
  на IP вместе с VLESS; ошибка не кешируется. Maintenance отдаёт JSON 503.
- Backup/verify проверяют Fernet-шифрование токенов Flow и ключей WGDashboard,
  если соответствующие таблицы присутствуют. Старые архивы без этих таблиц
  не отклоняются только из-за их отсутствия.
