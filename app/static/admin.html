Настройки магазина

Контакт поддержки и условия продажи применяются к новым обращениям и покупкам. Изменение текста не меняет уже оформленные заказы. Домен, ключи и адреса панелей настраиваются при установке или в своих разделах.

Редактор меню Telegram

Изменяйте подписи, порядок строк и видимость кнопок. «Купить VPN» остаётся обязательной. Дополнительно можно добавить две HTTPS-ссылки, например на ваш канал. Изменения применяются к новым сообщениям /start, а не к ранее отправленным кнопкам.

Предпросмотр новых кнопок

Предпросмотр не создаёт временную ссылку входа и не обращается к Telegram. Для проверки живого бота после сохранения отправьте /start.

Последние действия

Аналитика магазина

Отчёт за период до 366 дней. Заказы сгруппированы по времени оформления, их статусы отражают текущее состояние. Бесплатные trial и бонусные продления не считаются коммерческими продажами.

Реклама MTProxy: заявки

Приём, модерация и ручной учёт проверенных поступлений/полных возвратов. Размещения учитываются по ручным подтверждениям владельца. Управление узлом и расчёт чистой прибыли пока не автоматизированы. Доступы сотрудников ограничиваются назначенными ролями.

Сводка рекламы и расходы

Ручной учёт. Деньги считаются по времени записи поступления/возврата в журнал, расходы — по указанной дате. Остаток не является чистой прибылью: полнота расходов и обязательства проверяются владельцем. Состояния оплаченных заявок показаны на текущий момент независимо от периода.

Пустые границы — последние 30 суток. Максимальный период — 366 дней.

Учесть расход

Сохранение фиксирует уже понесённый расход. Перевода денег нет. Не вводите пароли, ФИО и банковские реквизиты.

Исключение ошибочной записи корректирует учёт, но не возвращает деньги. Причина остаётся в журнале.

Брони MTProxy

Планирование выполняется владельцем. Период не запускает узел автоматически; занятое размещение и пауза удерживают площадку до подтверждённой остановки.

Очередь остановок MTProxy

Снимок на момент обновления. Истёкший срок не останавливает спонсора и не освобождает площадку. Проверьте реальное состояние и сохраните ручное подтверждение.

Площадки MTProxy

Проверяйте показ канала настоящим Telegram-клиентом. Здесь сохраняется ваше подтверждение; команды узлу не отправляются. Пауза удерживает площадку, окончание требует подтверждённой остановки.

Состояние магазина

Локальный отчёт: очереди, настройки, наблюдение за worker и сохранённые результаты проверок серверов. Он не проверяет реальный VPN-трафик, списание денег или резервные копии и не выполняет запросов к провайдерам.

Протоколы подключения

Выберите технологию и проверьте требования к клиенту. «Адаптер в коде» означает реализацию выдачи в магазине; работа на вашем сервере требует отдельной проверки. Кандидаты для новых интеграций отмечены «В плане».

Наличие протокола в панели само по себе не включает его в продажу. TLS/REALITY и транспорт настраиваются вместе с протоколом.

Серверы

Новый сервер создаётся выключенным. Проверьте API, затем включите новые назначения. Проверка API не измеряет скорость и VPN-трафик.

Приглашения и бонусы

Приглашать может владелец действующей платной подписки. Новый аккаунт принимает приглашение до первого заказа или trial. Лимит резервируется при принятии, включая приглашения без оплаты; изменение настроек не меняет принятые условия. Бонус получает только пригласивший после одной подходящей подтверждённой оплаты. Бонусные дни продлевают платную подписку, вывода денег нет.

Пробный доступ

Один раз для Telegram-аккаунта без прежних заказов и подписок. Один основной профиль, без дополнительных устройств. Общий лимит активаций считается за всё время и не сбрасывается при редактировании.

Доступ к панели

При редактировании оставьте весь профиль подключения пустым, чтобы сохранить текущий. Для замены введите его полностью; сервер будет выключен до повторной проверки.

Выберите режим, поддерживаемый вашей панелью. Автоматического переключения API нет.

Remnawave v3: адрес панели укажите без /api. Создайте отдельный токен в настройках Remnawave и укажите UUID внутренних групп доступа. После сохранения нажмите «Проверить API», затем включите сервер. Пользователь и срок проверяются после записи; ссылка подписки берётся из панели.

VMess AEAD · 3x-ui Clients JSON API. Поддерживаются TCP+TLS и WebSocket+TLS. Создайте и проверьте VMess inbound в панели до подключения магазина. Проверка TLS обязательна.

Публичные адрес и порт должны вести на этот inbound; API-проверка не проверяет маршрут или сертификат VPN. TLS должен быть включён в самом inbound. Включите синхронизацию времени на сервере и устройствах.

Hysteria2 · S-UI apiv2. Прямое подключение по UDP/QUIC с TLS. До подключения магазина создайте inbound и проверьте его в клиенте.

Укажите адрес API панели с её путём, например https://panel.example/app, без /apiv2. Имя TLS и пароль Salamander должны совпадать с inbound. UDP-порт должен быть доступен; API-проверка не проверяет VPN-трафик. При редактировании оставьте весь профиль пустым для сохранения прежних настроек или заполните его целиком.

TUIC v5 · S-UI apiv2. QUIC/TLS с ALPN h3 и отдельными UUID/паролями. Создайте inbound и проверьте ручное подключение; 0-RTT должен быть выключен.

Алгоритм должен совпадать с inbound. UDP-порт должен быть доступен, сертификат — доверенным. Для изменения режима заполните профиль целиком. В обоих TLS-профилях панели укажите ALPN h3; 0-RTT, ECH и UDP-over-stream не поддерживаются этим этапом.

WGDashboard: адрес панели без /api; API-ключ создайте в её настройках. Сначала сохраните профиль и проверьте API. По умолчанию срок контролирует Shop. В карточке сервера можно включить дополнительное задание удаления на панели для новых заказов и продлений; текущие активные сроки автоматически не переносятся. Проверьте работу на тестовом сервере до начала продаж.

Проверьте параметры

После сохранения нажмите «Проверить API» в карточке сервера. Убедитесь, что VPN работает в клиенте, затем включите «Принимать новых».

Ключи и пароли не показываются в сводке. При замене профиля выдача будет выключена до проверки API и вашего включения.

Обновить доступ

Сначала создайте новый токен или измените пароль в самой панели, затем сохраните его здесь. Адрес, inbound и привязки подписок сохранятся.

Новые назначения и продления будут приостановлены до повторной проверки API и включения сервера. Уже выданные конфигурации эта операция не отзывает.
