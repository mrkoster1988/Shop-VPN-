# Проверка комплектного исходного кода

- 288 автоматических тестов Python (pytest) и 50 сценариев JavaScript (Node.js): пройдены.
- Синтаксис JavaScript: `node --check` для клиентского кабинета и админки.
- Синтаксис Bash: `bash -n scripts/wireguard-init.sh`.
- Компиляция Python: app, agent, scripts.

Проверены регистрация, пароль, сессия, выход, защита от cross-origin запросов,
доступ администратора, недоступность ненастроенных протоколов, серверная цена,
повтор отправки заказа, изоляция пользователей, продление без потери дней,
повтор подтверждения оплаты, шифрование, QR, восстановление после ошибки,
отключение просроченного доступа, подпись/срок данных Telegram, одноразовый вход,
проверка суммы и статуса ЮKassa, отмена ручного заказа, выдача WG с постоянным
ключом/IP, отзыв peer, аутентификация агента, запросы legacy 3x-ui,
создание платежа ЮKassa и обработка Stars pre-checkout/success/replay.

Дополнительно проверен адрес `/shop`: страницы и статические файлы, Origin без подпути,
путь cookies и выход, одноразовый вход с возвратом в `/shop/`, недоступность API
в корне, приватные конфигурации/QR/скачивание и возврат ЮKassa на `/shop/`.

В тестах внешние API и системная команда wg подменены контролируемыми ответами.
Реальные 3x-ui, WireGuard, Telegram, ЮKassa и Docker-сборка в этой среде не проверялись.
Визуальная проверка сайта в браузере не выполнялась.
Зависимости в среде проверки выдали одно предупреждение Starlette о будущем переходе
TestClient с httpx на httpx2; это не ошибка тестов и не влияет на обработку API магазина.
Перед публичным запуском выполните проверку на целевом сервере по README.md.
