# История изменений Pushok VPN

Формат версий: X.YYY. Новые версии добавляются сверху.

## [0.007] — 2026-11-04

- Список пользователей в админке с поиском по email, Telegram ID и номеру пользователя.
- Карточка клиента: подписки, действующий доступ, сроки, заказы и статусы оплаты/выдачи.
- Постраничный просмотр пользователей и заказов конкретного клиента.
- Пароли, VPN-конфигурации и ссылки оплаты исключены из новых API.
- Защита от отображения запоздавших ответов после выхода из админки или закрытия карточки.
- Проверки сценариев обработки данных админкой на JavaScript включены в CI.

## [0.006] — 2026-11-04

- Создание собственных тарифов через админку: срок, цена в рублях и Stars, название и постоянный код.
- Новые тарифы по умолчанию скрыты; доступность для покупателей включается администратором.
- Покупка и продление по новым тарифам на сайте и в Telegram без изменения исходного кода.
- Проверка кодов, защита от дубликатов, сохранение в базе и аудит создания тарифов.

## [0.005] — 2026-11-04

- Редактирование названий, сроков и цен в рублях и Stars в админке /shop/admin.
- Скрытие тарифов для новых покупок, хранение настроек в SQLite и журнал изменений.
- Безопасное обновление существующей базы и сохранение условий старых заказов.
- Проверка версии тарифа при покупке: изменившиеся условия нужно подтвердить заново.
- Защита от одновременного редактирования и отдельные заказы для разных версий тарифа.
- Сохранение пути /shop/ в адресной строке после возврата от оплаты.

## [0.004] — 2026-11-04

- GitHub CI: полные тесты магазина, оплаты, VPN-провайдеров и релизов.
- Автоматическая проверка синтаксиса JavaScript, Python и Bash.
- Публикация релиза только после успешного завершения общих CI-проверок.

## [0.003] — 2026-11-04

- Автоматические GitHub Releases при изменении CHANGELOG.md в main.
- Ручной запуск Actions → Release → Run workflow.
- Сводное описание всех версий после предыдущего опубликованного релиза.
- Проверки планирования релиза, пропуск повторного запуска и последовательная публикация.

## [0.002] — 2026-11-04

- Магазин доступен по адресу /shop: страницы, API, вход, конфигурации и QR-коды.
- Сессии ограничены путём магазина, возврат после оплаты ведёт в /shop/.
- Примеры Nginx и Caddy для сохранения основного сайта.

## [0.001] — 2026-11-04

- MVP Pushok VPN: сайт, кабинет, Telegram-бот и панель администратора.
- Выдача VLESS через legacy API 3x-ui 2.x и WireGuard через отдельный агент.
- Ручная оплата, ЮKassa и Telegram Stars.
- Продление, очередь выдачи, повторные попытки и отключение просроченного доступа.
