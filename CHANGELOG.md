# История изменений Pushok VPN

Формат версий: X.YYY. Новые версии добавляются сверху.

## [0.014] — 2026-11-05

- Лимиты дополнительных профилей по тарифам: от 0 до 20, основной профиль отдельно.
- Редактирование лимита в админке с версией и аудитом; условия видны в каталоге, подтверждении заказа и кабинете.
- Снимок лимита в заказе и применение к подписке только после успешной выдачи всего заказа.
- Снижение лимита сохраняет выданные ключи и блокирует только создание новых сверх лимита.
- Миграция прежних тарифов, заказов и подписок с сохранением лимита 4; старые запросы редактирования сохраняют лимит.
- Установщик фиксирован на v0.014; автоматическая миграция уже установленной другой версии не выполняется.

## [0.013] — 2026-11-05

- Установка одной командой с диалогом для Ubuntu 22.04/24.04 LTS и фиксированной версией исходников.
- Автоматическое создание секретов, Docker Compose, проверка локального сервиса и публичного HTTPS.
- Режимы нового HTTPS, существующего Nginx и внешнего прокси; маршрут /shop сохраняется.
- Резервная копия и восстановление Nginx при отказе проверки/перезагрузки; работающие сайты и контейнеры не удаляются.
- Повторный запуск сохраняет конфигурацию, ключ шифрования и идентичность volume; обновление старой установки не выполняется молча.
- Предварительный план без изменений, защита от параллельного запуска и проверки установщика в CI.

## [0.012] — 2026-11-05

- Отдельные профили устройств для VLESS и WireGuard: до четырёх дополнительных ключей на подписку, основной профиль сохраняется.
- Раздел «Устройства» в кабинете: название, создание, подключение через мастер и подтверждённый пользователем запрос отзыва.
- Постоянная очередь создания и отключения с повтором на том же сервере и ключе; защита от дубликатов запроса.
- Продление всех выданных профилей вместе с подпиской и отключение по окончании срока.
- Зашифрованные конфигурации, раздельные QR/скачивание и проверки владельца; локальный доступ закрывается сразу при запросе отзыва.

## [0.011] — 2026-11-05

- Мастер подключения в кабинете: выбор Android, iPhone/iPad, Windows, macOS и Linux, инструкции для VLESS и WireGuard.
- QR-код загружается по запросу; доступны скачивание, копирование и ручное выделение при отказе буфера обмена.
- Кнопки продления и возобновления выбирают исходный протокол и сохраняют существующую модель подписки.
- Приватные настройки очищаются при закрытии, выходе, смене аккаунта и истечении срока; запоздавшие ответы не восстанавливают их.
- Сценарии клиентского интерфейса включены в CI вместе с проверками админки.

## [0.010] — 2026-11-04

- Отдельный адаптер Clients JSON API с Bearer-токеном, явным выбором режима в админке и проверкой совместимости.
- Проверка UUID, subId, inbound, срока и состояния после записи; повтор после тайм-аута обновляет тот же доступ.
- Сохранение существующих параметров клиента при продлении и запрет смены API у сервера с подписками.
- Собственный план развития и сценарий стендовой приёмки; обзор и сравнения сторонних магазинов удалены из текущих файлов.

## [0.009] — 2026-11-04

- Реестр нескольких серверов VLESS legacy 3x-ui и WireGuard с локацией, лимитом подписок и режимами работы.
- Зашифрованные профили подключения, скрытые реквизиты, проверка API перед включением нового сервера.
- Назначение сервера до первого внешнего запроса; повторы выдачи и продления сохраняют сервер и ключ.
- Однократный импорт прежних .env-настроек и привязка старых подписок без переноса на другой сервер.
- Админка серверов, защита от конфликтов редактирования и смены endpoint у занятого сервера.
- Диагностика сохранённых профилей и тесты миграции, лимитов, ошибок API и сохранения привязки.

## [0.008] — 2026-11-04

- Постраничный список заказов в админке без ограничения последними 200 записями.
- Поиск по номеру заказа, email, Telegram ID и номеру покупателя.
- Совместные фильтры статуса заказа, способа оплаты и VPN-протокола.
- Переход из заказа в карточку покупателя; доступные действия определяются сервером.
- Защита от запоздавших ответов поиска и возврат на доступную страницу после обработки заказов.

## [0.007] — 2026-11-04

- Список пользователей в админке с поиском по email, Telegram ID и номеру пользователя.
- Карточка клиента: подписки, действующий доступ, сроки, заказы и статусы оплаты/выдачи.
- Постраничный просмотр пользователей и заказов конкретного клиента.
- Пароли, VPN-конфигурации и ссылки оплаты исключены из новых API.
- Защита от отображения запоздавших ответов после выхода из админки или закрытия карточки.
- Проверки сценариев обработки данных админкой на JavaScript включены в CI.

## [0.006] — 2026-11-04

- Создание собственных тарифов через админку: срок, цена в рублях и Stars, название и постоянный код.
- Новые тарифы по умолчанию скрыты; доступность для покупателей включается администратором.
- Покупка и продление по новым тарифам на сайте и в Telegram без изменения исходного кода.
- Проверка кодов, защита от дубликатов, сохранение в базе и аудит создания тарифов.

## [0.005] — 2026-11-04

- Редактирование названий, сроков и цен в рублях и Stars в админке /shop/admin.
- Скрытие тарифов для новых покупок, хранение настроек в SQLite и журнал изменений.
- Безопасное обновление существующей базы и сохранение условий старых заказов.
- Проверка версии тарифа при покупке: изменившиеся условия нужно подтвердить заново.
- Защита от одновременного редактирования и отдельные заказы для разных версий тарифа.
- Сохранение пути /shop/ в адресной строке после возврата от оплаты.

## [0.004] — 2026-11-04

- GitHub CI: полные тесты магазина, оплаты, VPN-провайдеров и релизов.
- Автоматическая проверка синтаксиса JavaScript, Python и Bash.
- Публикация релиза только после успешного завершения общих CI-проверок.

## [0.003] — 2026-11-04

- Автоматические GitHub Releases при изменении CHANGELOG.md в main.
- Ручной запуск Actions → Release → Run workflow.
- Сводное описание всех версий после предыдущего опубликованного релиза.
- Проверки планирования релиза, пропуск повторного запуска и последовательная публикация.

## [0.002] — 2026-11-04

- Магазин доступен по адресу /shop: страницы, API, вход, конфигурации и QR-коды.
- Сессии ограничены путём магазина, возврат после оплаты ведёт в /shop/.
- Примеры Nginx и Caddy для сохранения основного сайта.

## [0.001] — 2026-11-04

- MVP Pushok VPN: сайт, кабинет, Telegram-бот и панель администратора.
- Выдача VLESS через legacy API 3x-ui 2.x и WireGuard через отдельный агент.
- Ручная оплата, ЮKassa и Telegram Stars.
- Продление, очередь выдачи, повторные попытки и отключение просроченного доступа.
